[1m== Reading of the control[0m
   Impersonation works only with the PREVIEW token-exchange:v1 feature plus
   FGAP v1 policy wiring, on both 26.0.7 and 26.4.0. On a 26.4.0 with V2
   defaults it is rejected outright:
     "Parameter 'requested_subject' is not supported for standard token exchange"
   Turning token-exchange:v1 on also turns TOKEN_EXCHANGE_EXTERNAL_INTERNAL_V2
   OFF (see the feature listings above), so a deployment cannot run the legacy
   path and Option B's V2 path on the same server.
